# Security policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability involving screenshot disclosure, password redaction, archive extraction, local file access, or input capture.

Report it privately through [GitHub Security Advisories](https://github.com/thisistoni/Crumbtrail/security/advisories/new). Include the affected version, reproduction steps, expected impact, and any relevant project file or logs with sensitive content removed.

Crumbtrail does not request, store, or transmit account credentials. Never send real passwords or private screenshots in a report.
